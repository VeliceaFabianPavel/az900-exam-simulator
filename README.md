**A complete, free practice environment for Microsoft Azure Fundamentals (AZ-900).**
247 original practice questions, 42 study lessons, ten full 50-question exam forms, a timed
exam mode that looks and behaves like the real testing software, an untimed practice mode with
hints and per-question feedback, and a study guide that links straight into the questions.

It runs entirely in your browser. Nothing to install, no account, no sign-up, no tracking, no
ads, no paywall, no "premium tier". Open it and start studying.

---

## Why this exists

**I believe education should be free.**

Certification is one of the few ladders that people can climb from wherever they happen to be
standing. Then the tooling gets in the way. Good practice exams sit behind subscriptions.
Training platforms charge monthly. The study guides that actually explain things cost money, and
the practice software that would let you rehearse the real thing costs more.

None of that is a technical necessity. It is a business model.

So I read the official study guide, worked through every chapter, and built the thing I wished
had existed while I was preparing: a practice environment that behaves like the real exam, and
training material organised the way the paid platforms organise theirs — and I am giving it
away.

If it helps you pass, that is the whole return I am looking for. Pass it on.

## What this is

Two tools that share the same material.

### 1. The exam simulator

Modelled closely on the experience of sitting the real thing, because the format itself is worth
rehearsing. The first time you meet a candidate agreement screen, a countdown clock and a review
panel should not be on exam day.

- **Ten practice forms**, each 50 questions drawn from the bank
- **45 minutes** on the clock, **700 of 1000** to pass — matching the live exam
- **Blueprint-weighted forms**: every form is stratified to the published skills outline, so you
  always get 14 cloud concepts, 19 architecture and services, and 17 management and governance
- **Deterministic forms, shuffled delivery** — exam 3 always contains the same 50 questions, but
  the presentation order and the answer options are reshuffled on every attempt, so you cannot
  memorise "the answer is B"
- **The full delivery flow**: candidate agreement, exam overview, ready screen, question
  delivery, mark-for-review, review panel, score report, answer review
- **Exam toolbar** with question details, progress stepper, calculator, break screen and help
- **Score report** with a scaled score, a pass or fail verdict, and a breakdown by skills area so
  you know where to go back to

### 2. The training module

The study side is modelled on the way commercial training platforms such as GMetrix pair study
material with practice: you learn a topic, then you practise exactly that topic, and the two are
linked in both directions.

- **7 modules, 42 lessons**, one module per in-scope chapter of the study guide
- Every lesson gives you **what to know**, the **distinctions the exam actually turns on**, and
  the **pages in the study guide** the material was written against, so you can always check a
  claim against the source
- **Mark lessons as read**, with progress tracked per module and overall
- **Lessons link to questions**: each module tells you how many bank questions cover it
- **Questions link back to lessons**: in practice mode, revealing an answer offers a "Read the
  source" link that opens the exact lesson in a dialog, with the specific points that question
  tests highlighted

## Two ways to sit a form

You choose the mode before you start, and it is fixed for that attempt.

| | **Practice mode** | **Exam mode** |
|---|---|---|
| Clock | Counts **up**, no limit | Counts **down** from 45 minutes |
| Ends by itself | Never | Yes, when time runs out |
| Hints | Yes, on every question | No |
| Reveal the answer | Yes, whenever you want | No, not until you finish |
| Result after each question | Yes, with the reasoning | No |
| Links into the study guide | Yes | No |
| Scored | Yes | Yes |

### Practice mode in detail

- **Hint** — a nudge towards the idea a question turns on, without naming the answer
- **Show answer** — the keyed answer plus the full explanation, inline
- **Per-question result** — answer, press Next, and you get *"That is correct"*, *"That is not
  right"* or *"You skipped this one"* with your answer against the key and the reasoning. You can
  go straight back and change it. Turn this off in the toolbar if you would rather work straight
  through
- **Honest scoring** — the score report tells you how many questions you took a hint on and how
  many you revealed. Changing an answer after seeing the result counts as help, so the number
  means something

| Describe cloud concepts | 62 | 14 | 25–30% |

### Question formats

The real exam is not all multiple choice, so this is not either.

| Format | Count | What it looks like |
|---|---|---|
| Multiple choice | 195 | Single and multi-answer |
| Yes/No grids | 21 | A statement table, every row must be right |
| Drag and drop | 17 | Match values to targets |
| Drop-down completion | 10 | Complete each statement |
| Build list | 2 | Put steps in the correct order |
| Hot area | 2 | Select a region on a diagram |

Questions are written to be **genuinely discriminating**. Distractors come from the same
conceptual family, so you cannot eliminate by plausibility alone; stems carry the one detail that
decides the answer; and explanations name the trap as well as the answer. Several questions
deliberately punish the common half-truths — that a reservation paid up front is capital
expenditure, that a stopped virtual machine has stopped costing money, that an availability zone
protects against losing a region.

Every question carries the skills-outline objective it tests and the study guide chapter it came
from, which is what makes the two-way linking with the training module work.

## It works on your phone

The whole thing is built to be used on a phone, because that is where a lot of revision actually
happens — on a bus, in a queue, in the ten minutes before something else starts.

- The exam toolbar becomes a slide-in drawer
- The header collapses to question number, clock and a thin progress bar
- The footer becomes a stacked action bar with full-width Previous and Next
- Tables reflow into cards, and Yes/No radios become properly sized tappable pills
- Drag-and-drop questions work by tapping: tap a value, tap where it goes
- Build-list ordering uses arrow buttons rather than dragging
- Everything respects safe-area insets, so nothing hides under a notch or a home indicator
- Pinch-zoom is deliberately left enabled

Light, dark and system themes are all supported, everywhere.

Everything here was written while working through the official study guide:

> Jim Boyce — Sybex (Wiley)
> ISBN 9781394350018 (paperback) · 9781394350025 (ePDF) · 9781394350032 (ePub)

*The first edition of the same guide carries ISBNs 9781119770923, 9781119768203, 9781119771159
and 1119770920 — if that is the copy you own, the chapter structure is close enough to follow
along.*

**Nothing in this repository is copied from the book.** The guide is copyrighted, and it is
treated that way throughout:

- Every question, answer, explanation, hint and lesson is **original wording**
- The book is used as a source of **Azure facts**, not of text
- Every question carries a **chapter reference** and every lesson a **page range**, so any claim
  can be checked against the source
- The book itself is **never committed** to this repository — the PDF and everything derived from
  it are in `.gitignore`

If you are serious about this exam, **buy the book.** It is the source this was built from, it is
better than any free summary including this one, and the author deserves paying. This project is
a rehearsal environment, not a replacement for it.

### What is not covered

Deliberately out of scope, matching the way the material was built:

- **Chapter 4, core networking** — virtual networks, load balancers, VPN gateway, CDN
- **Performance-based lab exercises**
- **Case studies**

Everything else in the skills outline is covered.

## Run it yourself

You need the **.NET 10 SDK**. Nothing else.

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
dotnet run
```

Then open <http://localhost:5132>.

### Testing on your phone

The default profile only listens on localhost, so there is a second profile that listens on your
network:

```bash
dotnet run --launch-profile phone
```

Then browse to `http://<your-computer-ip>:5132` from a phone on the same Wi-Fi. You may need to
allow the connection through your firewall the first time.

## Deploying your own copy

The repository ships with a GitHub Actions workflow that publishes to GitHub Pages on every push
to `main`.

1. Fork or clone this repository
2. In **Settings → Pages**, set **Source** to **GitHub Actions**
3. Push to `main`

The workflow builds a release, rewrites the `<base href>` for your repository path, drops the
pre-compressed duplicates that Pages never serves, disables Jekyll, and adds an SPA fallback so
deep links and refreshes work. No configuration needed — it reads your repository name from the
build context.

## How it is built

| | |
|---|---|
| Framework | Blazor WebAssembly, .NET 10 |
| UI components | Microsoft Fluent UI Blazor 4.14.4 |
| Hosting | Static files — GitHub Pages, or any web server |
| Backend | None. There isn't one |

It is a fully static single-page application. The question bank and the training content are

### How questions and lessons find each other

Every question carries an `Objective` (the skills-outline bullet) and a `Reference` (the study
guide chapter). Every lesson carries the same two. That shared vocabulary is the whole linking
mechanism — no separate mapping table to maintain.

When you reveal an answer in practice mode, the app finds the lessons sharing that objective,
ranks them by how strongly their content matches the question, and highlights the specific
lesson points that question is testing. The matching is computed at runtime from term overlap,
so adding a question or a lesson wires itself up automatically.

## Adding or correcting questions

Questions are plain C#, one call per question. To add a multiple-choice item:

```csharp
yield return Mc("cc-063", D1, "Describe cloud computing", R1,
    """
    The scenario, written as prose.

    The question itself?
    """,
    [
        "The correct option.",
        "A plausible near miss.",
        "Another plausible near miss.",
        "A fourth option."
    ], "A",
    """
    Why the keyed answer is right, and why the closest distractor is not.
    """,
    """
    A hint that narrows the field without naming the answer.
    """);
```

The helpers `Mc`, `YesNo`, `Drag`, `Dropdowns`, `Build`, `HotImage` and `HotNested` cover every
supported format and are documented in `Services/QuestionBank.cs`.

**Found a mistake?** Please open an issue. Every question carries its chapter reference, so
mistakes are checkable against the source — and a wrong answer key in a study tool is worse than
no study tool. Corrections are the most valuable contribution you can make.
